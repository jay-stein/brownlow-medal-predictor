## Goal

Hunt for fourth-quarter disposals data, then build and run the 2026 Brownlow forecast with calibrated vote spreads and win probabilities.

## Q4 Data Hunt — Conclusion

Per-quarter player stats are **not publicly available**, so the fourth-quarter disposals feature cannot be built without a paid provider:

| Source | Result |
|---|---|
| Public AFL API `playerStats/match/{id}` | Totals only; period query params ignored |
| `/cfs/afl/stats/match/…`, `/cfs/afl/periodStats/match/…` | Endpoints exist but return 403 Forbidden (Stats Pro premium) |
| `api.afl.com.au/statspro` host | 404 on public paths; site uses a signed-URL keyserver (premium) |
| fitzRoy, AFL Tables, Footywire, Squiggle | Totals only |
| DFS Australia public download | Totals + CBA/kick-ins/TOG, no quarter splits |

Documented in `data/README.md` so it is not re-investigated.

## Results — 2026 Forecast

Model: ranking LambdaMART trained 2012–2025 (123,087 player-games, 268 rounds); `tau = 0.845` from 2,555 OOS matches; effect scale 0.4; 10,000 simulations.

| Player | Exp. votes | 90% interval | P(outright) | P(first or joint) | P(top 5) |
|---|---|---|---|---|---|
| Nick Daicos | 41.0 | 32–49 | 76.2% | 79.9% | 99.8% |
| Bailey Smith | 34.4 | 25–44 | 17.7% | 21.0% | 96.5% |
| Marcus Bontempelli | 27.1 | 18–35 | 0.9% | 1.4% | 70.6% |
| Will Ashcroft | 24.2 | 17–32 | 0.1% | 0.3% | 48.7% |
| Patrick Cripps | 22.8 | 14–32 | 0.5% | 0.6% | 37.7% |

Specification sensitivity (first-or-joint across effect scales 0.0/0.2/0.4): Daicos 80–92%, Smith 10–21%. Backtest calibration context: contender 90% coverage 0.885, favourite won 5 of 11 seasons, eventual winner averaged a 36% pre-count probability.

## Important Decisions

1. **Eligibility deferred**: the AFL award endpoint exposes `eligible` only around the count; the forecast documents that it is not applied. An ineligible player's match votes would still affect other totals.
2. **Specification sensitivity** reported across persistent-effect scales rather than a single point estimate.
3. **`tau` fitted on all earlier out-of-sample seasons** (2013–2025, 2,555 matches) for the production forecast.
4. **Top-5 inclusivity**: boundary ties count, so expected top-5 counts can exceed 5.

## Blockers / Follow-ups

- Phase 3b match-block bootstrap model variation remains open (the persistent effect is the only simulation uncertainty at present).
- Voting-history features could lift the over-performing-winner cases seen in 2024/2025.
- Eligibility application at the award stage needs an in-count season source.
- Close-game performance proxies are a possible substitute for the unavailable Q4 disposals.
